# FONarch 1.0

GitHub **Latest** tag `v1.0.0`. Attach:

- `FONarch_1.0.0_aarch64.dmg` (Mac Apple Silicon, signed + notarized)
- `FONarch_1.0.0_x64-setup.exe` (Windows x64, unsigned NSIS)

`v0.9.0-mac` and `python-v1` stay as older releases.

---

FONarch finds Adobe Creative Cloud’s hidden livetype fonts, names them, and either drops a sorted folder on your Desktop (**GATHER**) or zips that same result (**ARCHIVE**).

**1.0** = Mac Apple Silicon **and** Windows both have a download.

### Mac (Apple Silicon)

Signed and notarized (Developer ID Application: Michael Jones).

1. Download `FONarch_1.0.0_aarch64.dmg`
2. Open it and drag **FONarch** to **Applications**
3. Launch. macOS may once say it was downloaded from the internet — Open.

### Windows

Unsigned. SmartScreen will likely warn.

1. Download `FONarch_1.0.0_x64-setup.exe`
2. If Windows says it protected your PC: **More info** → **Run anyway**
3. Install, then GATHER / ARCHIVE from the window

### In the app

- **GATHER** — dated folder, fonts renamed and sorted by family
- **ARCHIVE** — same, then a `.zip`; no leftover folder
- Gear — themes, save location, About, Quit

Default save place is the Desktop. The gear can point it elsewhere. Source livetype is never written.

### Requirements

- Mac with Apple Silicon **or** Windows 10/11 x64
- Adobe Fonts / Creative Cloud livetype cache already on the machine

Intel Macs: not this drop.
