# FONarch 0.9.0 — Mac preview

GitHub **Latest** tag `v0.9.0-mac`. Attach `FONarch_0.9.0_aarch64.dmg`. `python-v1` stays as an older release.

---

FONarch finds Adobe Creative Cloud’s hidden livetype fonts, names them, and either drops a sorted folder on your Desktop (**GATHER**) or zips that same result (**ARCHIVE**).

This is a **Mac Apple Silicon** preview. Signed and notarized (Developer ID Application: Michael Jones). Windows is next. Not 1.0.

### Install

Open the `.dmg`, drag **FONarch** to **Applications**, launch. macOS may once say it was downloaded from the internet — Open.

### In the app

- **GATHER** — dated folder, fonts renamed and sorted by family
- **ARCHIVE** — same, then a `.zip`; no leftover folder
- Gear — themes, save location, About, Quit

Default save place is the Desktop. Source livetype is never written.

### Requirements

- Mac with Apple Silicon (M1 / M2 / M3 / M4)
- Adobe Fonts / Creative Cloud livetype cache already on the machine

Intel Macs and Windows: not this file.

### Not affiliated with Adobe

Personal backup of fonts you already have. Not a redistribution tool. Encrypted `.e` blobs are skipped.
