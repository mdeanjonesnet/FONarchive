# Vis reference (not shipped)

`BG 02.mov` is an Envato Elements loop used as **art direction** for the FONarch vis.

| | |
|---|---|
| What it is | 10 s, 3840×2160, 30 fps, Apple ProRes 422 |
| Size | ~705 MB |
| Motion | Camera locked. Wireframe heightfield **undulates in place** (not a flythrough) |
| Color | White on black; the app tints from the theme accent |

**Do not ship this file. Do not commit it.** The app vis is a WebGL/GLSL recreation (see `mockups/vis-preview.html` and `docs/DECISIONS.md`). Envato’s license covers use of their clip inside an end product, not dropping a 4K ProRes into a tiny Apache-2.0 app — and GLSL is the better match anyway (theme color, idle/running speed, a few KB).
